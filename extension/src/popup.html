Same Page for Web Registration

What this extension reads and sends

  • It reads section numbers, times, days and instructor names from the section tables you are looking at.
  • It never reads your name, USC ID, login, cart or any form, and it never clicks or registers for you.
  • Requests go only to the Same Page server below, without cookies. Claude runs on that server, so no AI key lives in this extension.
